# Documentation Assets

These Telegram chat captures illustrate a release proposal delivered as a Markdown file,
the user's approval and the agent's publication confirmation. Telegram's English translation
is enabled in the captured chat.

| Asset | Dimensions | Content |
| --- | --- | --- |
| [chat-1.webp](chat-1.webp) | 1178 × 1218 pixels | File delivery, a short caption and the user's approval reply |
| [chat-2.webp](chat-2.webp) | 1178 × 1218 pixels | Release confirmation with session context and a GitHub link preview |

The images use lossless WebP without embedded metadata. Both captures retain their original
resolution and decoded pixels; no resizing, cropping or color reduction is applied.

The [main README](../../README.md) displays them side by side, with clickable previews that
open the full-size files.

When replacing a capture, update its description, dimensions and corresponding README preview.
